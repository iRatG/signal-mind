# Prototype: Daily News Pressure Radar Report

Companion artifact for [Ticket 04 - Report Prototype](../tickets/04-report-prototype.md). This file is the concrete example Airat reviews to accept (or send back for revision) the report shape decided in that ticket's `## Working Decision`.

**Everything below is illustrative, synthetic data** — headlines, source counts, and dates are invented to exercise every section of the shape; they are not a real pipeline run. Anywhere a market-side "historical correlation" claim appears, it is explicitly a placeholder for the kind of statement Ticket 10's Runner/Auditor pipeline will eventually produce from real backtested data — Ticket 10 hasn't run yet, so no real number is asserted here.

Метод: local_similarity_graph_v1 + LLM labels + section-dedup + pressure_score_v2

## Executive Summary

Сегодняшний главный импульс — «Банк России сохранил ключевую ставку на 18%» с 11 источниками

## Требует проверки

- **Оценка ущерба от паводка в размере "более 40 млрд рублей"**: флаг `unsupported_number` —
  цифра встречается только в одном источнике без указания методологии подсчёта, LLM не смогла
  найти независимое подтверждение. Кластер исключён из основного сигнала до подтверждения.
- **Кластер "реакция аналитиков на решение ЦБ"**: флаг `llm_fallback_heuristic` — LLM-разметка
  не сработала (таймаут API), кластер помечен эвристикой без содержательной интерпретации;
  требует ручной проверки перед тем, как на него полагаться.

## Шум/рутина

6 рутинных/неподтверждённых кластеров исключено (курсы валют на завтра, погода, спортивный
календарь, телепрограмма — не показаны).

## Что смотреть дальше

- [Главный импульс] Следить за риторикой ЦБ на следующей пресс-конференции — ужесточение тона
  без изменения ставки часто предшествует реальному ужесточению через 1-2 заседания.
- [Что вспыхнуло — делистинг] Проверить, появится ли официальное подтверждение делистинга
  от самой биржи в течение 48 часов.
- [Синхронно подхватили] Отследить, войдёт ли уточнённая формула бюджетного правила
  в опубликованный проект бюджета на следующей неделе.
- [Один источник — аномалия] Дождаться окна повторной проверки (см. Ticket 02 follow-up window)
  на кадровые изменения в банке — подтверждение ещё двумя источниками переводит это
  в "Один источник — аномалия (подтверждено)", отсутствие — в "Шум/рутина".

## Example 2 — Technical/Ops report (a day with no reportable signal)

Triggered when the run clears Ticket 03's hard blockers (articles and clusters exist, no collector failure) but no cluster reaches any of the 5 non-noise signal types. Sent to Airat only, visually distinct from a product report (exact visual treatment — color, marking — is Ticket 07/Editor scope; this Markdown skeleton only fixes the content).

```markdown
# Технический отчёт — Пульс Дня (нет сигнала)
Период: 2026-07-31
Topic run: topic_graph_20260801T060000000000Z
Режим: daily · ТЕХНИЧЕСКИЙ ОТЧЁТ, НЕ ПРОДУКТОВЫЙ

Прогон завершился штатно: собрано 118 статей из 14 источников, построено 9 кластеров.
Ни один кластер не прошёл порог ни одного из 5 содержательных типов сигнала — весь день
классифицирован как шум/рутина. Продуктовый отчёт за этот период не формируется.

## Общий прогресс (Overall progress)

Метод: pressure_score_v2, без изменений с прошлого прогона. Один параметр реестра
(source_spread порог для Synchronized story) остаётся на пересмотре в Ticket 12.

## Технический журнал (сводка — полная версия в db/knowledge.md)

- Квартальная активность LLM-разметки: 0 fallback-срабатываний за сегодня (норма).
- Источники: все 14 отдали данные, коллектор без ошибок.
- quality_flag_count: 0.

Никаких действий не требуется.
```
