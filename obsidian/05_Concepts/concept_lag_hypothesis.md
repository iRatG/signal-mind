# Concept: Lag Hypothesis

## Definition
Инструмент A в момент T предсказывает инструмент B в момент T+N.
Лаг N — время передачи информации через экономический механизм.

## Текущий LAG_SWEEP
```python
LAG_SWEEP = [0, 7, 14, 0, 30, 0, 60, 0, 90, 0]
```
Уникальные лаги: 0, 7, 14, 30, 60, 90 дней.

## Экономическая интерпретация лагов
| Лаг | Механизм |
|-----|---------|
| 0 дней | Синхронная реакция (общий фактор) |
| 7 дней | Новостной эффект, первичная реакция рынка |
| 14 дней | Вторичная реакция, корпоративные решения |
| 30 дней | Бизнес-цикл, месячные данные |
| 60 дней | Отчётный период, квартальные ожидания |
| 90 дней | Бюджетный цикл, стратегические решения |

## Нетестированные лаги
- 21 день (3 недели — цикл решений ЦБ?)
- 45 дней (между 30 и 60)
- 180 дней (полугодовой)

## Правило
Для каждой пары (A, B): перебрать все лаги из LAG_SWEEP.
Оптимальный лаг — где r максимален. Документировать экономическое обоснование.
